# 《决战苏富比》基础游戏规则

> 文档状态：基础规则、竞拍流程与联机异常规则已确认  
> 最后更新：2026-09-01

## 1. 术语约定

为避免“回合”一词产生歧义，项目内统一采用以下术语：

- **整局游戏**：从游戏开始到最终现金排名公布的完整过程。
- **阶段（Round）**：整局游戏共进行 4 个阶段。
- **拍卖轮次（Auction Turn）**：一名主持人打出一张藏品并完成一次拍卖与现金结算的过程。
- **主持人（Auctioneer）**：当前拍卖轮次中选择并打出藏品的玩家。
- **手牌藏品**：玩家持有但尚未打出拍卖的藏品，对其他玩家不可见。
- **已购藏品**：玩家通过拍卖获得、摆放在场上的藏品，对所有玩家可见。

## 2. 游戏模型

游戏包含以下四类核心模型：

1. **收藏家（玩家）**：3～8 名。
2. **银行**：负责管理公共现金、阶段结算、回收藏品及收取罚款。
3. **现金**：玩家参与竞拍和最终胜负结算的资源。
4. **藏品**：用于拍卖、收藏和阶段结算的唯一卡牌。

## 3. 玩家信息与公开信息

### 3.1 私密信息

以下信息仅玩家本人可见：

- 当前持有的手牌藏品；
- 当前持有的现金数量。

### 3.2 公开信息

以下信息对所有玩家可见：

- 玩家在当前阶段通过拍卖购买到的藏品；
- 藏品卡上公开展示的属性；
- 当前主持人；
- 当前阶段各种收藏系列已被购买的藏品数量；
- 已经公开发生的拍卖及现金交易记录。

## 4. 游戏初始设置

### 4.1 初始现金

每名玩家在游戏开始时获得 **150 万**现金。

项目内部建议统一使用“万元”作为金额单位，因此初始现金可表示为 `150`。

### 4.2 初始手牌

游戏开始时，从固定藏品库中随机向每名玩家发放藏品手牌。初始手牌数量由玩家人数决定：

| 玩家人数 | 每人初始手牌 |
|---:|---:|
| 3 | 11 张 |
| 4 | 10 张 |
| 5 | 10 张 |
| 6 | 8 张 |
| 7 | 8 张 |
| 8 | 6 张 |

玩家的初始手牌对其他玩家不可见。

### 4.3 首位主持人

游戏开始时，从所有玩家中随机选择一名玩家作为首位主持人。

## 5. 藏品模型

### 5.1 唯一性与固定藏品库

- 每张藏品都是独一无二的；
- 游戏使用固定不变的藏品库；
- 藏品库总计 **84 张**藏品；
- 藏品一旦在阶段结算时被银行回收，便永久作废，不再参与本局游戏。

### 5.2 藏品属性

每张藏品包含以下四个核心属性：

1. **稀有度**；
2. **竞拍方式**；
3. **收藏系列**；
4. **是否为失窃藏品**。

每张藏品还应具有不可重复的唯一标识，用于程序内部识别。

### 5.3 稀有度

藏品稀有度使用皇冠数量表示，共分为 5 级：

- 1 皇冠；
- 2 皇冠；
- 3 皇冠；
- 4 皇冠；
- 5 皇冠。

阶段结束时，藏品价值按照以下公式计算：

```text
单张藏品价值 = 藏品皇冠数 × 该收藏系列在本阶段获得的单价
```

### 5.4 收藏系列

藏品分为黑、蓝、绿、黄、红五个收藏系列：

| 收藏系列 | 藏品数量 |
|---|---:|
| 黑色 | 15 张 |
| 蓝色 | 16 张 |
| 绿色 | 17 张 |
| 黄色 | 18 张 |
| 红色 | 18 张 |
| **合计** | **84 张** |

### 5.5 失窃藏品

- 图片边框为黑色的藏品属于失窃藏品；
- 图片边框为白色的藏品属于正常藏品；
- 所有失窃藏品的竞拍方式只能是暗标；普通藏品也可以采用暗标；
- 阶段结束时，根据失窃藏品所属收藏系列在本阶段的价值排名确定是否罚款；
- 如果该系列排名第 1、2、3 名，失窃藏品具有价值，持有者必须向银行缴纳等同于该藏品价值的罚款；
- 如果该系列排名第 4、5 名，失窃藏品价值为 0，不触发罚款，银行也不向持有者支付现金；
- 阶段结算后，该失窃藏品由银行回收并永久作废；
- 玩家现金不足以缴纳全部罚款时，现金余额可以降为负数，负数部分作为玩家对银行的负债；
- 负债玩家后续获得任何现金收入时，收入首先自动冲抵其负债，余额恢复至 0 以上后才形成可使用现金。

失窃状态与收藏系列中的“黑色系列”是两个彼此独立的属性，不应混淆。

### 5.6 竞拍方式

每张藏品固定具有以下五种竞拍方式之一：

1. 公开竞价；
2. 顺序竞价；
3. 一口价；
4. 联合拍卖；
5. 暗标。

#### 5.6.1 通用报价、参与资格与结算规则

- 游戏内现金与报价统一以 **1 万元**为最小金额单位，所有金额必须是 1 万元的整数倍；
- 公开竞价、顺序竞价和普通暗标的最低有效报价为 **1 万元**；
- 一口价允许主持人将固定售价设为 **0 元**；
- 失窃藏品暗标允许玩家提交 **0 元**报价；
- 除上述明确允许 0 元的情况外，0 元不属于有效报价；
- 现金余额大于 0 的玩家，可以在不超过其当前现金余额的范围内报价；
- 现金余额等于 0 或小于 0（处于负债状态）的玩家，不能作为竞买者参与公开竞价、顺序竞价、一口价、普通暗标以及联合后的普通拍卖；
- 现金余额等于 0 或小于 0 的玩家仍可参与失窃藏品暗标，但只能提交 0 报价；
- 现金余额等于 0 或小于 0 的玩家仍可响应其他玩家发起的联合拍卖，提供一张符合条件的藏品并成为新主持人；成为新主持人不代表其获得竞买资格；
- 主持人为一口价藏品设定的售价不得超过其当前可用现金；当主持人的现金余额等于 0 或小于 0 时，只能将一口价设为 0；
- 系统应在玩家报价或主持人定价时立即校验参与资格和现金上限，不接受不符合条件的报价；
- 除失窃藏品暗标和联合拍卖的特殊结算规则外，其他拍卖默认按以下方式结算：
  - 其他玩家购得藏品时，购得者将全部成交款支付给主持人；
  - 主持人购得藏品时，主持人将全部成交款支付给银行；
- 特殊竞拍方式的结算规则与通用规则冲突时，以特殊规则为准。

#### 5.6.2 公开竞价

1. 起拍价为 0；
2. 包括主持人在内、现金余额大于 0 的玩家都可以参与出价；
3. 首次有效报价至少为 1 万元；之后每次新报价必须高于当前最高报价，最低加价幅度为 1 万元，并且不得超过报价者当前持有的现金；
4. 每当出现一个有效的新最高报价，重新开始 30 秒倒计时；
5. 公开竞价不要求玩家逐一响应；如果当前 30 秒内没有出现更高报价，则倒计时结束；
6. 当前最高报价者以自己的报价购得藏品，并按通用结算规则支付成交款；
7. 如果倒计时结束时无人提交有效报价，则主持人以 0 元获得该藏品，无需向银行付款。

#### 5.6.3 一口价

1. 主持人在 1 分钟内设定一个固定售价；如果超时未设定，系统自动将固定售价设为 0 元；
2. 主持人现金余额大于 0 时，固定售价不得超过其当前现金；主持人现金余额等于 0 或小于 0 时，只能将固定售价设为 0；
3. 从主持人左手边第一位玩家开始，其他玩家按顺时针顺序依次决定是否按该固定售价购买藏品；
4. 每名玩家有 30 秒时间作出决定；超时未选择视为拒绝购买；
5. 首位选择购买的玩家立即以固定售价购得藏品，之后的玩家不再进行选择；
6. 如果其他玩家全部拒绝购买，则由主持人以该固定售价买下藏品，并将成交款支付给银行。

#### 5.6.4 顺序竞价

1. 从主持人左手边第一位玩家开始，按顺时针顺序依次行动，主持人最后行动；
2. 每名玩家在本次拍卖中只有一次出价机会，并有 30 秒时间完成操作；超时未操作视为放弃；
3. 首位有效报价至少为 1 万元；之后玩家可以开出一个高于当前最高有效报价的价格，也可以放弃，最低加价幅度为 1 万元；
4. 未高于当前最高有效报价的报价视为放弃；
5. 报价不得超过报价者当前持有的现金；
6. 主持人完成出价或放弃后，本次竞价结束；
7. 本轮开出最高有效报价的玩家以该报价购得藏品，并按通用结算规则支付成交款；
8. 如果所有玩家均放弃、没有产生有效报价，则主持人以 0 元获得该藏品，无需向银行付款。

#### 5.6.5 暗标（普通藏品）

1. 包括主持人在内，所有具备竞买资格的玩家都要提交一个报价；
2. 玩家分别秘密提交自己的报价；报价至少为 1 万元，并且不得超过各自当前持有的现金；
3. 报价阶段持续 30 秒，期间玩家无法看到其他玩家的报价；
4. 具备竞买资格但在 30 秒内未提交报价的玩家视为放弃，不参与结果比较；
5. 倒计时结束后，同时公开所有已提交的有效报价；
6. 出价最高的玩家以自己的报价购得藏品，并按通用结算规则支付成交款；
7. 如果两个或多个玩家的最高报价相同，则从主持人左手边第一位玩家开始按顺时针顺序比较座次，顺序最靠前的并列玩家购得藏品；主持人在该顺序中排在最后。

#### 5.6.6 暗标（失窃藏品）

所有失窃藏品的竞拍方式固定为暗标，并采用以下特殊规则：

1. 报价流程和 30 秒倒计时与普通暗标相同；
2. 除主持人外，其他玩家都要提交报价；主持人可以自行选择是否参与本次暗标；
3. 现金余额大于 0 的玩家可以提交不超过其现金余额的报价；现金余额等于 0 或小于 0 的玩家只能提交 0 报价；
4. 任何必须报价或主动选择参与的玩家，如果在 30 秒内未提交报价，系统自动为其提交 0 元报价；
5. 倒计时结束后，同时公开所有参与者的报价；
6. 出价最低的玩家购得该失窃藏品；
7. 购得藏品的最低出价者不需要支付自己的报价；
8. 除购得者外，其他所有参与报价的玩家都要将自己的报价支付给银行；
9. 如果主持人参与报价但没有购得藏品，主持人同样需要将自己的报价支付给银行；
10. 如果两个或多个玩家的最低报价相同，则从主持人左手边第一位玩家开始按顺时针顺序比较座次，顺序最靠前的并列玩家购得失窃藏品；主持人在该顺序中排在最后；
11. 本次拍卖不向主持人支付拍卖收入。

#### 5.6.7 联合拍卖

联合拍卖不能包含任何失窃藏品。用于联合的两张藏品必须属于同一个收藏系列，并且作为第二张藏品加入拍卖的藏品，其竞拍方式不能是联合拍卖。

联合拍卖中的阶段结束条件按藏品加入顺序逐张判断：

1. 首先检查主持人打出的初始联合藏品；
2. 如果初始联合藏品是该系列在当前阶段被打出的第 6 张，则该藏品立即作废，阶段结束，不再选择或邀请第二张藏品；
3. 如果初始联合藏品未触发阶段结束，则主持人选择自己的第二张藏品，或邀请其他玩家提供第二张藏品；
4. 确定第二张藏品后，再检查该藏品是否成为该系列在当前阶段被打出的第 6 张；
5. 如果第二张藏品触发阶段结束，则初始联合藏品和第二张藏品均作废，不进行拍卖，阶段立即结束；
6. 只有两张藏品均未触发阶段结束时，才执行联合拍卖。

联合拍卖分为以下两种模式。

##### 模式 A：主持人使用自己的两张藏品

1. 主持人打出一张竞拍方式为联合拍卖的初始藏品；
2. 主持人再从自己的手牌中选择一张与初始藏品同系列、非失窃且竞拍方式不是联合拍卖的藏品；
3. 以第二张藏品标明的竞拍方式拍卖这两张藏品；
4. 最终购得者一次获得两张藏品；
5. 两张藏品共用一个成交价，并按照所采用竞拍方式的结算规则完成付款；若该竞拍方式没有特殊付款规则，则采用通用结算规则。

##### 模式 B：邀请其他玩家共同拍卖

1. 主持人打出一张竞拍方式为联合拍卖的初始藏品；
2. 从主持人左手边第一位玩家开始，其他玩家按顺时针顺序依次决定是否拿出一张符合条件的藏品参与联合；
3. 每名被邀请玩家有 30 秒时间响应；超时未响应视为拒绝联合，并继续询问下一位玩家；
4. 参与联合的藏品必须与初始藏品属于同一个收藏系列、不是失窃藏品，并且其竞拍方式不是联合拍卖；
5. 现金余额等于 0 或小于 0 的玩家仍可以提供符合条件的藏品参与联合；
6. 首位同意并提供合规藏品的玩家成为**新主持人**，原主持人称为**旧主持人**，不再继续询问后续玩家；
7. 如果没有任何玩家参与联合拍卖，则旧主持人免费获得自己打出的初始藏品，该藏品进入旧主持人的公开已购藏品区域；
8. 如果有玩家参与，则按照新主持人提供的第二张藏品所标明的竞拍方式，对两张藏品进行拍卖；
9. 旧主持人、新主持人及其他玩家是否可以竞买，仍须遵守现金余额对应的通用参与资格；现金余额等于 0 或小于 0 的玩家可以担任联合方，但不能在联合后的普通拍卖中出价；
10. 最终购得者一次获得两张藏品；
11. 成交款拆分时，旧主持人对应的份额向上取整，新主持人对应的份额向下取整：

    ```text
    旧主持人份额 = 向上取整（成交价 ÷ 2）
    新主持人份额 = 向下取整（成交价 ÷ 2）
    ```

12. 成交款按购得者身份进行结算：
    - **旧主持人购得**：旧主持人向新主持人支付新主持人份额，并向银行支付旧主持人份额；
    - **新主持人购得**：新主持人只需向旧主持人支付旧主持人份额，新主持人份额无需支付；
    - **其他玩家购得**：购得者支付完整成交价，其中旧主持人获得旧主持人份额，新主持人获得新主持人份额；
13. 例如成交价为 11 万元，则旧主持人份额为 6 万元，新主持人份额为 5 万元：
    - 旧主持人购得时，向新主持人支付 5 万元、向银行支付 6 万元；
    - 新主持人购得时，只向旧主持人支付 6 万元；
    - 其他玩家购得时，向旧主持人支付 6 万元、向新主持人支付 5 万元；
14. 拍卖结束后，由新主持人左手边第一位玩家成为下一拍卖轮次的主持人；
15. 因此，旧主持人与新主持人之间的玩家可能被跳过，本轮不再按旧主持人的相邻座位移交主持权。
## 6. 拍卖轮次

每个拍卖轮次按以下基础流程进行：

1. 当前主持人从自己的手牌中选择一张藏品；
2. 主持人将该藏品公开打出；
3. 根据该藏品指定的竞拍方式进行拍卖；
4. 主持人原则上可以参与自己主持的拍卖；失窃藏品暗标中，主持人可以选择不参与；
5. 确定购得藏品的玩家和最终成交价；
6. 按照对应竞拍方式的规则完成现金结算；没有特殊结算规则时，采用通用结算规则；
7. 购得藏品的玩家将藏品公开摆放在自己的已购藏品区域；联合拍卖的购得者同时公开获得两张藏品；
8. 若没有触发阶段结束条件，则默认由当前主持人左手边的玩家成为下一位主持人；
9. 主持权按顺时针方向依次轮换；邀请其他玩家共同拍卖时，改为从新主持人的左手边继续。

无论藏品由其他玩家还是主持人自己购得，该藏品都视为成交，并进入购得者的公开已购藏品区域。联合拍卖无人参与时由主持人免费获得初始藏品，也视为已购藏品。

## 7. 阶段结束条件

整局游戏共进行 4 个阶段。

在一个阶段内，按收藏系列分别统计所有玩家已经购买并公开摆放的藏品数量。

当某一颜色收藏系列已经有 **5 张**藏品被玩家购买后，如果当前主持人再打出该颜色的第 **6 张**藏品，则：

1. 第 6 张藏品立即作废；
2. 不再执行该藏品对应的竞拍；
3. 当前阶段立即结束；
4. 进入本阶段的藏品价值与现金结算。

触发阶段结束的第 6 张藏品不计入已购买数量，也不参与阶段价值排名或结算。

联合拍卖一次涉及两张同系列藏品，须按加入顺序逐张检查：

- 初始联合藏品先接受第 6 张判定；如果触发，则仅该初始藏品作废，且不再选择第二张藏品；
- 初始联合藏品未触发时，再对第二张藏品进行判定；如果第二张触发，则初始联合藏品与第二张藏品均作废；
- 任一藏品触发第 6 张判定后，联合拍卖均不执行，当前阶段立即结束。

### 7.1 下一阶段主持人

完成当前阶段的藏品价值与现金结算后，由**触发该阶段结束的主持人左手边第一位玩家**担任下一阶段的首位主持人。

如果阶段结束由联合拍卖中的任一藏品触发，则无论第二张藏品由谁提供，都以打出初始联合藏品的**旧主持人**为基准，由旧主持人左手边第一位玩家担任下一阶段首位主持人。

第 4 阶段结束后整局游戏结束，不再移交主持权。

### 7.2 手牌全部耗尽

如果所有玩家的手牌均已耗尽，但仍未打出某个收藏系列的第 6 张藏品，则不再继续拍卖，当前阶段立即结束，并按照场上已经购买的藏品正常进行价值排名、奖励、罚款和回收结算。

- 如果该情况发生在第 1、2、3 阶段，则完成当前阶段结算后，按照补牌与主持权规则进入下一阶段；
- 如果该情况发生在第 4 阶段，则完成当前阶段结算后结束整局游戏，并公布最终现金排名。

## 8. 阶段价值排名与单价

阶段结束时，统计场上各收藏系列在本阶段已被购买的藏品数量，并按数量进行排名。

五个收藏系列首先按照本阶段已被购买的藏品数量从多到少排序。若两个或多个系列的藏品数量相同，则按照以下固定优先级决定先后名次：

```text
黑色 > 蓝色 > 绿色 > 黄色 > 红色
```

排名对应的本阶段新增单价如下：

| 数量排名 | 本阶段新增单价 |
|---:|---:|
| 第 1 名 | 30 万 |
| 第 2 名 | 20 万 |
| 第 3 名 | 10 万 |
| 第 4 名 | 0 |
| 第 5 名 | 0 |

因此，每个阶段都会产生唯一的第 1 至第 5 名，不存在并列名次。

每个收藏系列的结算单价可以跨阶段累加：

```text
本阶段该系列最终单价 = 该系列此前阶段累计单价 + 本阶段新增单价
```

## 9. 阶段藏品与现金结算

确定各收藏系列的最终单价后，对玩家本阶段购买的所有藏品逐张结算。

### 9.1 正常藏品

对于正常藏品：

1. 按“皇冠数 × 系列最终单价”计算藏品价值；
2. 银行向持有该藏品的玩家支付等值现金；
3. 银行回收该藏品；
4. 被回收的藏品永久作废，不再参与后续阶段。

### 9.2 失窃藏品

失窃藏品按照其所属收藏系列在本阶段的排名进行结算。

#### 所属系列排名第 1、2、3 名

1. 按“藏品皇冠数 × 该系列最终单价”计算藏品价值；
2. 该价值即为失窃藏品的罚款金额；
3. 持有该藏品的玩家向银行支付等值现金；
4. 例如某系列排名第 2、对应单价为 20 万，一张该系列的 3 皇冠失窃藏品应缴纳 `20 万 × 3 = 60 万`罚款；
5. 银行回收该藏品，该藏品永久作废。

#### 所属系列排名第 4、5 名

1. 该系列本阶段单价为 0，因此失窃藏品价值为 0；
2. 玩家不需要缴纳罚款；
3. 银行也不向玩家支付任何现金；
4. 银行回收该藏品，该藏品永久作废。

#### 现金不足与负债

1. 玩家必须全额承担失窃藏品罚款，即使当前现金不足；
2. 罚款可以使玩家现金余额降为负数；
3. 负数余额表示该玩家对银行的负债；
4. 玩家后续通过出售藏品、阶段结算或其他途径获得现金时，系统首先使用收入自动偿还银行负债；
5. 只有在现金余额恢复为正数后，超出负债的部分才成为玩家可使用的现金。

示例：玩家当前现金为 20 万，需要缴纳 60 万罚款，则结算后现金为 -40 万。之后玩家获得 70 万收入时，先冲抵 40 万负债，最终可用现金为 30 万。

## 10. 阶段间补牌

仅在第 2 阶段和第 3 阶段开始时，向每名玩家补充随机藏品手牌。

补牌数量由玩家总人数决定：

| 玩家人数 | 第 2 阶段每人补牌 | 第 3 阶段每人补牌 |
|---:|---:|---:|
| 3 | 8 张 | 8 张 |
| 4 | 5 张 | 5 张 |
| 5 | 3 张 | 3 张 |
| 6 | 3 张 | 3 张 |
| 7 | 2 张 | 2 张 |
| 8 | 2 张 | 2 张 |

基础规则中未要求在第 4 阶段开始时补牌，因此默认第 4 阶段不补牌。

## 11. 游戏结束与胜负

完成第 4 阶段的结算后，整局游戏结束。

游戏只按照所有玩家最终的现金净余额从高到低排序，并向所有玩家公示最终排名：

- 正现金余额越高，排名越高；
- 现金余额为 0 时，高于任何负债玩家；
- 玩家均为负债时，负债越少、现金净余额越接近 0，排名越高；
- 不使用累计购得藏品数量、皇冠总数或其他指标打破平局；
- 两名或多名玩家的最终现金净余额完全相同时，获得相同名次；
- 如果最高现金净余额由多名玩家共同持有，则这些玩家均为本局胜者。

## 12. 掉线、重连与中途退出

### 12.1 掉线与座位保留

- 玩家短暂掉线时，系统保留其座位、身份、现金、负债、手牌、已购藏品及其他游戏状态；
- 玩家可以使用同一微信账号重新连接，并恢复到原有座位和最新游戏状态；
- 玩家掉线不会暂停整局游戏，也不会阻止其他在线玩家继续操作；
- 服务端是游戏状态和规则判定的唯一权威，游戏运行不依赖房主或当前主持人持续在线。

### 12.2 离线期间的操作

掉线玩家轮到操作时，仍按照相应竞拍方式已经确定的超时规则处理：

- 顺序竞价超时视为放弃；
- 一口价购买超时视为拒绝购买；
- 普通暗标超时视为放弃，不参与结果比较；
- 失窃藏品暗标超时由系统自动提交 0 元报价；
- 联合拍卖邀请超时视为拒绝联合；
- 主持人设置一口价超时，系统自动将售价设为 0 元；
- 公开竞价无需逐一等待玩家响应，按最高报价的 30 秒倒计时正常推进。

### 12.3 中途退出与长期离线

- 正在进行的游戏不允许玩家主动退赛或释放座位；
- 玩家关闭小程序、切换网络或长时间未连接时，统一视为离线；
- 长期未重连的玩家持续由系统按照各操作的超时规则处理，直到本局结束；
- 房主离线不影响游戏继续进行，也不会转移或终止游戏房间；
- 游戏结束后，系统为所有参赛玩家保存本局最终排名和结算记录，包括离线玩家。

## 13. 基础状态流转

```text
创建游戏
  → 3～8 名玩家加入
  → 初始化固定藏品库
  → 每人获得 150 万现金
  → 随机发放初始手牌
  → 随机选择首位主持人
  → 第 1 阶段
      → 主持人打出藏品
      → 执行藏品指定的竞拍方式
      → 结算拍卖并公开已购藏品
      → 顺时针移交主持权
      → 重复，直到某颜色的第 6 张藏品被打出，或所有玩家手牌耗尽
      → 若由第 6 张藏品触发，则按规则将相关藏品作废
      → 计算系列排名与累计单价
      → 回收藏品并完成奖励或罚款
  → 第 2 阶段开始前补牌
  → 第 2 阶段
  → 第 3 阶段开始前补牌
  → 第 3 阶段
  → 第 4 阶段（不补牌）
  → 第 4 阶段结算
  → 按最终现金数量公布排名
```
